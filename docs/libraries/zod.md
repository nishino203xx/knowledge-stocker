# Zod

## 概要

TypeScript 向けのスキーマ定義およびバリデーションライブラリ

## 採用理由

Qiita / dev.to などの外部 API は型保証がなく、レスポンスの構造が変わった場合に実行時エラーが発生する恐れがあるが、Zod を用いることで不正なデータを検知できる。また、スキーマと型定義の二重管理が不要となる。（`z.infer<typeof Schema>`でスキーマから型定義の抽出が可能）

valibot でも上記を満たせるが、比較的新しいライブラリであり、他プロジェクトでの採用事例はまだ多くない。習得した知識を別の開発でも活かしやすい点を重視して、今回は Zod を採用した。

## 他の候補

### yup

- 静的型推論をサポートしているが、信頼性が低い

### valibot

- Zod と同様に TypeScript-first な設計
- Zod と比較して軽量

### joi

- スキーマから型定義を取得するために外部ツールが必要

### io-ts

- 関数型プログラミングの知識が必要で学習コストがやや高い
- 今回は API -> フロント (decode)のみで encode は不要
